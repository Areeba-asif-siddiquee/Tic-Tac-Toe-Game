A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript. This project is perfect for practicing frontend development skills.

Features:-
. Playable for two players (Player X and Player O).
. Simple, responsive, and user-friendly interface.
. Keeps track of the game status and declares the winner or a draw.

Technologies Used:-
HTML: Structure of the game.
CSS: Styling and layout.
JavaScript: Game logic and interactivity.
